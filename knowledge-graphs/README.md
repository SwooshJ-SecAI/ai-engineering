# Knowledge Graph Systems

![Knowledge](https://img.shields.io/badge/Domain-Knowledge%20Graphs-purple?style=flat-square)
![Data](https://img.shields.io/badge/Focus-Entity%20Modeling-green?style=flat-square)

Patterns for building and querying organizational knowledge graphs that serve as persistent intelligence layers for AI agent systems. Covers entity modeling, relationship design, ontology construction, and integration with agent reasoning workflows.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Topics

- Entity schema design for organizational knowledge
- Relationship modeling and edge type taxonomy
- Ontology construction for domain-specific graphs
- Search, expansion, and graph traversal patterns
- Knowledge graph as agent memory substrate
- Automated knowledge ingestion from documents and conversations
- Graph maintenance: deduplication, conflict resolution, decay
