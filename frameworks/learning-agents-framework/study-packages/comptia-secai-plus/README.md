# CompTIA SecAI+ (CY0-001) — Study Package

A complete study package generated by the Learning Agents Framework V2, covering the security of AI systems and the use of AI in security operations. SecAI+ sits at the intersection of the two disciplines: it assumes Security+ foundations and extends them to the unique risks and opportunities that AI introduces.

## What This Covers

AI security is not "regular security with a model bolted on." AI systems fail in ways traditional software does not: they can be poisoned during training, manipulated at inference, and made to leak their training data. This package treats AI as a new attack surface layered on top of classic security, and also as a new class of defensive tooling.

## How To Use These Materials

Work the numbered files in order: detailed notes, then first principles for the hard concepts, then quizzes and notecards for recall, then the assessment as a readiness check. If you have not completed Security+ material, start there — SecAI+ assumes it.

## Study Approach

The defining skill this cert tests is thinking about AI as *both* an asset to protect and a tool to wield, while never forgetting the classic controls underneath. The deconstruction in these notes repeatedly ties AI-specific risks back to the CIA triad — because that is how the exam frames "best response" questions.
