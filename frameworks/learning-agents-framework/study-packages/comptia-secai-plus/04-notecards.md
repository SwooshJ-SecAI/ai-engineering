## AI Fundamentals

**Q:** Two attack surfaces created by the training/inference split?
**A:** Training data (poisoning) and inference input (evasion).

**Q:** What are model weights/parameters, security-wise?
**A:** The learned knowledge — intellectual property; theft enables replication.

**Q:** Which learning type underpins security anomaly detection?
**A:** Unsupervised learning (baselines normal, flags deviations).

## AI Attacks

**Q:** Attack that corrupts the training set?
**A:** Data poisoning.

**Q:** Poisoning that implants a hidden trigger?
**A:** Backdoor (targeted) poisoning.

**Q:** Attack using imperceptible input perturbations at inference?
**A:** Evasion / adversarial example.

**Q:** Attack that reconstructs an equivalent model via queries?
**A:** Model extraction.

**Q:** Attack that reconstructs training data from a model?
**A:** Model inversion.

**Q:** Direct vs indirect prompt injection?
**A:** Direct = user types it; indirect = planted in content the model later reads.

**Q:** Shared root cause of prompt injection and SQL injection?
**A:** Data interpreted as instructions (no code/data separation).

**Q:** Risk of giving a model tools and autonomy to act?
**A:** Excessive agency — impact scales with capability.

## Securing AI

**Q:** Technique adding noise so no single record is memorized?
**A:** Differential privacy.

**Q:** Training across decentralized data without centralizing it?
**A:** Federated learning.

**Q:** Defense that trains on adversarial examples?
**A:** Adversarial training.

**Q:** Two attacks slowed by rate limiting and query monitoring?
**A:** Model extraction and evasion probing.

**Q:** Control for excessive agency?
**A:** Least privilege for AI + human confirmation for high-impact actions.

## SecOps with AI

**Q:** Risk of trusting model output as safe code/commands?
**A:** Insecure output handling.

**Q:** Risk of concentrating detection in one AI system?
**A:** Single point of failure / blind spot if poisoned or evaded.

**Q:** Why does explainability matter operationally?
**A:** Analysts must know why something was flagged to act; auditors may require reasoning.

## Governance

**Q:** Why does a model reproduce bias?
**A:** It learns the patterns — including biases — in its training data.

**Q:** Framework for AI risk management (govern/map/measure/manage)?
**A:** NIST AI Risk Management Framework.

**Q:** Core ethical control for consequential AI decisions?
**A:** Meaningful human oversight (human in/on the loop).

**Q:** The unifying SecAI+ frame for any topic?
**A:** Which property is at risk, at which lifecycle stage, and what control reduces it.
