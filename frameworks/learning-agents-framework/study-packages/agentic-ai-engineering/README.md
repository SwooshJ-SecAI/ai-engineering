# Agentic AI Engineering — Study Package

A complete study package generated by the Learning Agents Framework V2, covering the fundamentals of building agentic AI systems — LLM-based systems that reason, plan, use tools, and act toward goals rather than only responding to a single prompt.

## What This Covers

An agent is more than a chatbot. It perceives, decides, acts through tools, observes results, and loops until a goal is met. This package builds that concept from the smallest unit (the reason-act loop) up to multi-agent orchestration and the engineering concerns that make agents reliable and safe.

## How To Use These Materials

Work the numbered files in order. The notes build the conceptual model; the first-principles file reasons through the design decisions that separate a reliable agent from a fragile demo; the quizzes and notecards drill the vocabulary and patterns; the assessment tests design judgment with scenarios.

## Study Approach

Agentic AI is an engineering discipline, not a prompt trick. The recurring theme in these materials: an agent's power comes from the loop and its tools, and its risks come from the same place. Every reliability and safety concept traces back to controlling what the agent can do and verifying what it produces.
