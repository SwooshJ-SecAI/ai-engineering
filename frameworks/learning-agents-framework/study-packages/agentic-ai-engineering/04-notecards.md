## Foundations & Loop

**Q:** Three things that make a system agentic?
**A:** Goal-directedness, autonomy, tool use.

**Q:** What fundamentally distinguishes an agent from a single LLM call?
**A:** The act-observe-adjust feedback loop.

**Q:** The five parts of the agent loop?
**A:** Perceive, reason, act, observe, repeat until done.

**Q:** What does ReAct interleave?
**A:** Explicit reasoning and actions.

**Q:** Why are stop conditions required?
**A:** Prevent infinite loops, thrashing, and runaway cost.

**Q:** Up-front planning vs dynamic re-planning trade-off?
**A:** Up-front is efficient but brittle; dynamic is robust but costlier.

## Tools & Memory

**Q:** Who executes a tool call?
**A:** The orchestration layer; the model only emits the request.

**Q:** Why narrow, well-described tools?
**A:** The model selects from descriptions; clarity drives correct selection.

**Q:** Three memory types?
**A:** Short-term (context), long-term (persisted/retrieved), working (scratchpad).

**Q:** What problem does long-term memory solve?
**A:** Finite context window — retrieve only relevant past knowledge.

**Q:** How is relevant memory retrieved?
**A:** Nearest-neighbor search in embedding space.

## Orchestration

**Q:** Orchestrator-worker pattern?
**A:** Lead agent decomposes, delegates to specialists, synthesizes.

**Q:** Workflow vs agent — when each?
**A:** Workflow for fixed known steps; agent for adaptive paths.

**Q:** Benefit of multi-agent specialization?
**A:** Narrow scope = better decisions; plus parallelism.

**Q:** Cost of multi-agent?
**A:** Coordination complexity and more failure points.

**Q:** Purpose of human-in-the-loop?
**A:** Approve consequential actions before execution.

## Reliability, Evaluation & Safety

**Q:** Why do agent errors compound?
**A:** Each step feeds the next; early errors propagate.

**Q:** What do structured outputs (JSON schema) buy?
**A:** Machine-checkable, reliable downstream handling.

**Q:** Four agent evaluation metrics?
**A:** Task success, trajectory quality, tool-use correctness, cost/latency.

**Q:** Hidden instructions in content an agent reads?
**A:** Indirect prompt injection.

**Q:** Core agent safety controls?
**A:** Least privilege, sandboxing, human confirmation for high-impact actions.

**Q:** Why do capability and risk share one root?
**A:** Both come from the agent's ability to act through tools.
