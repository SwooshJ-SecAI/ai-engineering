## General Concepts

**Q:** The three properties of the CIA triad?
**A:** Confidentiality, Integrity, Availability.

**Q:** What property means a party cannot deny an action?
**A:** Non-repudiation (integrity + authentication, delivered by digital signatures).

**Q:** Control that substitutes when the primary is not feasible?
**A:** Compensating control.

**Q:** The four control natures?
**A:** Technical, Managerial, Operational, Physical.

**Q:** Zero Trust core premise?
**A:** Never trust, always verify — every request, regardless of origin.

**Q:** Which Zero Trust plane decides vs enforces?
**A:** Control plane decides (policy engine); data plane enforces (policy enforcement point).

## Threats & Vulnerabilities

**Q:** Self-propagating malware needing no user action?
**A:** Worm.

**Q:** Malware that hides by subverting the OS, often at kernel level?
**A:** Rootkit.

**Q:** Malware living in memory using legitimate tools like PowerShell?
**A:** Fileless malware.

**Q:** Spear phishing aimed at executives?
**A:** Whaling.

**Q:** Root cause of SQL injection?
**A:** Untrusted data interpreted as instructions; fix with parameterized queries.

**Q:** A vulnerability with no available patch?
**A:** Zero-day.

**Q:** TOCTOU refers to what vulnerability class?
**A:** Race condition (time-of-check to time-of-use).

## Architecture

**Q:** Network zone isolating public-facing servers?
**A:** DMZ.

**Q:** The three data states?
**A:** At rest, in transit, in use.

**Q:** Hardest data state to protect?
**A:** In use (in memory).

**Q:** Who secures customer data/config in the cloud?
**A:** The customer (shared responsibility model).

## Operations

**Q:** The five authentication factor categories?
**A:** Know, have, are, somewhere you are, something you do.

**Q:** Why are two passwords not MFA?
**A:** Both are "something you know" — same category.

**Q:** Authorization model where permissions attach to roles?
**A:** RBAC.

**Q:** Symmetric vs asymmetric — which is fast, which solves key distribution?
**A:** Symmetric is fast; asymmetric solves key distribution.

**Q:** What does salting defeat?
**A:** Precomputed rainbow table attacks.

**Q:** What three properties does a digital signature provide?
**A:** Integrity, authentication, non-repudiation.

**Q:** First incident-response action for an actively spreading host?
**A:** Containment (isolate).

**Q:** SIEM's core value?
**A:** Correlation of logs across sources.

**Q:** RTO vs RPO?
**A:** RTO = how fast to restore; RPO = how much data loss is tolerable.

**Q:** The 3-2-1 backup rule?
**A:** Three copies, two media types, one offsite.

## Program Management

**Q:** Risk formula?
**A:** Likelihood × Impact.

**Q:** Four risk treatments?
**A:** Accept, avoid, transfer, mitigate.

**Q:** ALE formula?
**A:** ALE = SLE × ARO, where SLE = asset value × exposure factor.

**Q:** Who determines purpose and means of processing personal data?
**A:** Data controller.

**Q:** Policy vs standard vs procedure vs guideline?
**A:** Intent / mandatory specifics / step-by-step / recommendation.
