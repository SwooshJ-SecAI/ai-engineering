## Domain: AI/ML Fundamentals

**Q1.** Which relationship is correct?
- A) ML is a superset of AI
- B) Deep learning is a subset of machine learning
- C) Generative AI contains deep learning
- D) AI is a subset of ML

**Answer: B.** The nesting is AI > ML > DL > GenAI. Deep learning is a subset of ML.

**Q2.** A team needs to detect anomalies in network traffic with no labeled examples of attacks. Which learning paradigm fits?
- A) Supervised
- B) Unsupervised
- C) Reinforcement
- D) None; labels are required

**Answer: B.** Unsupervised learning finds structure/anomalies without labels.

**Q3.** Which AWS service is the end-to-end managed platform for building, training, and deploying custom ML models?
- A) Amazon Rekognition
- B) Amazon SageMaker
- C) Amazon Comprehend
- D) Amazon Polly

**Answer: B.** SageMaker is the custom-ML anchor service.

## Domain: Generative AI Fundamentals

**Q4.** A task requires deterministic, factual output from an LLM. How should temperature be set?
- A) High
- B) Low
- C) It has no effect
- D) Exactly 1.0 always

**Answer: B.** Low temperature sharpens the distribution toward the most probable tokens — more deterministic and factual.

**Q5.** Which AWS service provides managed access to foundation models via API without managing infrastructure?
- A) SageMaker
- B) Amazon Bedrock
- C) EC2
- D) Lambda

**Answer: B.** Bedrock is the serverless foundation-model service.

**Q6.** What are embeddings?
- A) Encrypted prompts
- B) Numerical vectors capturing semantic meaning of text
- C) Model weights
- D) Billing units

**Answer: B.** Embeddings are semantic vectors; they enable similarity search and RAG.

## Domain: Applications of Foundation Models

**Q7.** A company wants an LLM to answer questions using their frequently-updated internal knowledge base. What is the BEST approach?
- A) Fine-tune the model weekly
- B) Retrieval-Augmented Generation (RAG)
- C) Increase temperature
- D) Train a new model from scratch

**Answer: B.** RAG injects current, private data at query time — no retraining, and updates are immediate.

**Q8.** Providing a few examples inside the prompt to steer the model is called:
- A) Fine-tuning
- B) Few-shot prompting
- C) RAG
- D) Reinforcement learning

**Answer: B.** Examples in the prompt = few-shot prompting.

**Q9.** When is fine-tuning the MOST appropriate choice?
- A) The model needs current facts about your data
- B) You need to durably change the model's behavior/style and cheaper methods fall short
- C) You want to reduce inference cost
- D) You want zero training cost

**Answer: B.** Fine-tuning durably changes behavior; it is the last resort after prompt engineering and RAG.

**Q10.** A model produces confident but factually false statements. This is:
- A) Drift
- B) Hallucination
- C) Bias
- D) Overfitting

**Answer: B.** Confidently wrong generation is hallucination; ground with RAG and constrain with guardrails.
