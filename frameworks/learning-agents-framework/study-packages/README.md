## The Five-Layer Structure

Every package contains the same five files, designed as a learning path:

1. **`01-detailed-notes.md`** — Core knowledge, built from the smallest causal unit upward. Each concept explains *why* it exists before *what* it does.
2. **`02-first-principles.md`** — The hardest concepts reasoned from fundamentals, targeting the topics people usually memorize and therefore misapply.
3. **`03-quizzes.md`** — Practice questions with full explanations, organized by domain.
4. **`04-notecards.md`** — Condensed Q/A pairs for spaced-repetition review.
5. **`05-assessment.md`** — A scenario-based self-assessment with an answer key and scoring guidance.

## How To Study With These

Work the files in numerical order. Read the notes without skimming. Work the first-principles breakdowns until the logic feels intuitive, not memorized. Use the quizzes to test application, the notecards for final-days review, and the assessment as a readiness gate. The assessments deliberately weight scenario reasoning over recall — because that is what the real exams test.
