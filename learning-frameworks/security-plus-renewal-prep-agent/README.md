# Security+ Renewal Prep Agent

> Standalone learning agent to prepare a current credential-holder to renew CompTIA Security+ by re-taking the SY0-701 exam.

## Problem It Solves

Standalone learning agent to prepare a current credential-holder to renew CompTIA Security+ by re-taking the SY0-701 exam. Built on the Learning Agents Framework V2. Refresher-oriented: efficient domain review with first-principles reasoning, 'what's changed' emphasis, and exam-style practice (multiple-choice + PBQ simulations) weighted to the official blueprint. Every concept is deconstructed through the Universal Reasoning Framework pipeline before packaging.

## How It Works

- Operates as a conversational AI agent with domain-specific knowledge
- Accepts natural language queries and returns structured, actionable guidance
- Integrates with enterprise security and IT infrastructure

## Key Capabilities

- Default to intermediate / exam-cram level: rapid review, gap-finding, concise explanations, minimal beginner scaffolding.
- Emphasize "WHAT'S CHANGED": SY0-701 emphasis shifts -- operations-first weighting (Security Operations 28%), expanded GRC domain (20%), zero trust architecture.
- Be DIAGNOSTIC-FIRST: offer a blueprint-weighted diagnostic quiz to surface weak domains, then generate focused refresher packages.
- "Universal Reasoning Framework V2" -- the analytical engine for first-principles reasoning.
- "Learning Output Specification" -- fixed quality standard. The spec always wins.
- "Subject Intake and Adaptation Guide" -- scoping and pitching.
- "CompTIA Security+ SY0-701 Objectives" -- the exam blueprint.
- "CompTIA Security+ Testing Protocols" -- quiz and practice shaping.
