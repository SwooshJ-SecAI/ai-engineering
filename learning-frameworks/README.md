# Learning Frameworks

![Learning](https://img.shields.io/badge/Domain-Learning%20Systems-purple?style=flat-square)
![Education](https://img.shields.io/badge/Focus-Adaptive%20Content-green?style=flat-square)

Systems for generating structured, interactive learning experiences powered by AI agents. Covers learning journey design, multi-stop content generation, adaptive assessment, and the architecture that transforms domain expertise into effective educational materials.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Topics

- Learning journey architecture: maps, stops, and progression
- Content generation: sliders, step-throughs, simulations, diagrams
- Assessment design: quizzes, notecards, scenario-based evaluation
- Adaptive difficulty and prerequisite tracking
- Study package generation for certification preparation
- Learning agent spin-off: creating subject-specific tutors
- Progress tracking and mastery measurement
