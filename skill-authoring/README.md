# Skill Authoring

![Skills](https://img.shields.io/badge/Domain-Skill%20Engineering-purple?style=flat-square)
![Methodology](https://img.shields.io/badge/Focus-SKILL.md%20Spec-green?style=flat-square)

The methodology and tooling for converting validated agent workflows into reusable, deterministic skill definitions. Documents the complete skill lifecycle from workflow observation through formalization, evaluation, and iterative improvement.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Topics

- SKILL.md specification: frontmatter, steps, triggers, inputs
- Workflow observation and procedure extraction techniques
- Deterministic vs agentic step design
- Trigger phrase engineering and intent matching
- Evaluation generation and test case authoring
- The test-improve loop: systematic skill refinement
- Skill cataloging and discoverability patterns
