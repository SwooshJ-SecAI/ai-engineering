# Agent Architecture

![AI](https://img.shields.io/badge/Domain-Agent%20Design-purple?style=flat-square)
![Patterns](https://img.shields.io/badge/Focus-Architecture%20Patterns-green?style=flat-square)

Design patterns and engineering principles for building AI agents that operate reliably in enterprise environments. Covers the full agent lifecycle from persona design through instruction engineering, context management, connector integration, and iterative refinement.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Topics

- Agent instruction authoring: structure, specificity, and constraint design
- Persona engineering for domain-specific agent behavior
- Context window management and memory architecture
- Action connector integration patterns
- Multi-agent coordination and handoff protocols
- Agent evaluation frameworks and accuracy measurement
- Reference file management and knowledge injection
